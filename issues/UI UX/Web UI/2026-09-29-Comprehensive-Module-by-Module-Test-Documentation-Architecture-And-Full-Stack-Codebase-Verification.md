## Issue 1: Module-Wise Test Report Architecture, Codebase Verification, and Realtime Specification Alignment

| Attribute | Details |
| :--- | :--- |
| **Project Overview** | Quality assurance documentation, subsystem verification, and test report architecture across all 15 core modules of the F&B Management and TableFlow platform. |
| **Problems Identified** | Historical test reports were fragmented, used obsolete 5-state table models instead of the implemented 7-state machine, assumed flat 18% global taxes instead of item-level 5% GST (`GstTaxTag`), missed the 5-second KDS Served Undo window, lacked documentation for the L8/L5 dual-lock check-in draft resolution flow, and contained outdated underscore-formatted Socket.io event names. |
| **Resolution** | Authored and deeply verified 15 individual module `.md` test reports inside `Test Reports/` against the authoritative source code (`backend/src/routes.ts`, `prisma/schema.prisma`, `backend/src/realtime/`, `backend/src/services/`, and `web-frontend/src/`). Documented verified workflows: 7-state table lifecycle, Redis lock ownership attribution (`Locked by: {Name} · {Role}`) with `403 FORBIDDEN_NOT_OWNER` enforcement, L8 draft vs L5 assignment switching, advance deposit pre-payment gates, 3-second order idempotency, ordering lock on bill request (`isBillRequested` / `BILL_REQUESTED`), Waiter Station "Reopen Ordering", 5-second sliding served undo manager (`servedUndoManager.ts`), itemized GST math on service-charge basis, in-memory cart reservations (`activeReservationsMap`), camera lifecycle management in `/quick-attendance`, and centralized dot-notation Socket.io event dictionary (`SOCKET_EVENTS`) across dedicated rooms (`kds:kitchen`, `kds:bar`, `staff:ready`, `staff:requests`, `tables:all`, `billing:all`, `customer:token:*`, `table:*`). |
| **Activities Completed** | Traced every test scenario across backend services, Express routes, Prisma schema enums, and React components; cleaned out all deprecated artifact references; assigned truthful execution statuses (`Code Verified`, `Documented`, `Requires Manual Verification`); verified that zero production source code was modified and zero test code was added; published 15 verified test reports. |
