## Issue 4: Metro NativeWind Windows Path Resolution, Socket.IO Client Dependency, and Component Export Alignment

| Attribute | Details |
| :--- | :--- |
| **Project Overview** | Build pipeline stabilization, runtime package dependency resolution, and component export alignment across the Native Mobile Frontend toolchain (Expo 56, Metro Bundler, NativeWind v4, React 19). |
| **Problems Identified** | 1. `socket.io-client` was missing from `frontend/package.json`, causing module resolution failures during bundling. <br>2. Windows file system paths with spaces (`D:\Cloud Shift Solutions Intern\...`) were split into unquoted arguments by NativeWind's internal Tailwind CLI spawner, triggering `Error running TailwindCSS CLI`. <br>3. Windows backslashes in stylesheet imports were being unescaped into control characters (`\f`, `\n`) by the nativewind transformer. <br>4. `MainAppShell.tsx` was defined with only a named export (`export const MainAppShell`) while `App.tsx` imported it as a default import (`import MainAppShell from ...`), resolving to `undefined` and throwing `Uncaught Error: Minified React error #130`. <br>5. `AppIcon.tsx` was missing explicit mappings for customer/staff action icons (`home`, `rotate-ccw`, `phone-call`, `clipboard-list`, `receipt`, `trash-2`, `utensils-crossed`, `shopping-bag`, `shopping-cart`, `flame`, `chef-hat`, `check-circle-2`, `sparkles`, `key-round`, `ticket`, `search`, `filter`, `log-out`). |
| **Resolution** | 1. Installed `socket.io-client@^4.8.4` in `frontend/package.json` and wired `frontend/src/services/socket.ts`. <br>2. Updated `frontend/metro.config.js` to pass `cliCommand: "npx tailwindcss"` into `withNativeWind`, avoiding path string splitting. <br>3. Wrapped `resolveRequest` in `metro.config.js` after `withNativeWind` to intercept and resolve all `global.css` cache paths cleanly on Windows. <br>4. Added `export default MainAppShell;` to `MainAppShell.tsx` to support both named and default imports, eliminating React Error #130. <br>5. Expanded `AppIcon.tsx` with complete Lucide icon mappings and robust fallback handling. |
| **Activities Completed** | Resolved all bundling errors, confirmed `npx expo export --platform web` bundles cleanly with exit code 0 (`Web Bundled 2239 modules -> Exported: dist`), verified runtime stability, and updated application entry points. |
